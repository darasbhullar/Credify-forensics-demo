What Credify Does

AI-powered media authenticity detection for the modern web.

Cryptographic C2PA Gate

Decodes binary JUMBF credentials. Valid signatures bypass model execution for instant, zero-cost authentication.

Semantic Visual Forensics

SigLIP-2 ViT encoder combined with a custom U-Net transposed decoder maps pixel-level manipulation heatmaps.

Frequency Domain Scans

Computes 2D Fast Fourier Transforms (FFT) to identify high-frequency upsampling grid artifacts from generators.

Temporal Frame Checking

Iteratively scans video sequences to catch short face-swaps or frame manipulations by calculating consistency metrics.

Low-Latency Hardware

Fully optimized pipeline running inference on high-throughput GPU infrastructure in less than 165ms.

Domain-Aware Veto

Differentiates illustration noise from standard photo textures to prevent false alarms on high-contrast artistic assets.

Technology Stack

Built with modern, production-grade technologies for reliability and performance.

FastAPI Core Pipeline

High-throughput Python backend implementing asynchronous frame slicing and REST APIs for web playground actions.

SigLIP-2 & Spatial U-Net

Google's 400M parameter visual encoder paired with transposed convolutional U-Net decoders to compute spatial segmentation maps.

2D Fast Fourier Transform

Extracts radial frequency log-magnitude spectra from grayscaled inputs to catch upsampling checkerboard patterns.

C2PA JUMBF Provenance Scanner

Instantly reads content credentials signatures at binary headers, bypassing deep networks for verified files.

Mixed-Precision CUDA

Leverages half-precision floating-point (FP16/BF16) and gradient checkpointing on NVIDIA L4 instances to reduce memory footprints.

Privacy Gating

All file evaluations run purely in-memory. Zero file logging, disk persistence, or secondary model training on uploads.
